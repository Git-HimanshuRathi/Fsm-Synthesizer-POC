● Key Features

  • Canvas-based FSM editor with drag & drop
  • State creation, editing, and deletion
  • Transition drawing with condition labels
  • Undo/redo support for all operations
  • Right-click context menus
  • FSM → digital circuit synthesis
  • Integrated into CircuitVerse simulator

● Project Structure

simulator/src/
fsm/
FSM.js — state machine model
FSMState.js — state nodes
FSMTransition.js — transitions
ContextMenu.js — context menu
UndoHistory.js — undo/redo
fsmEditor.js — editor UI
fsmSynthesizer.js — synthesis logic
css/fsmEditor.css — styles

● Synthesis Pipeline

FSMEditor → User draws states & transitions on canvas
FSM Model → Captures state graph (states, transitions, conditions)
fsmSynthesizer → Converts FSM definition to gate-level logic
CircuitVerse → Renders synthesized circuit in the simulator
